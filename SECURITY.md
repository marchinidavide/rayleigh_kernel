# Security

This repository is mathematical proof software.  A security report should
also be used for a proof or reproducibility issue such as an unsound axiom,
an omitted hypothesis, an incorrect certificate, or a build that cannot be
reproduced from the pinned dependencies.

Please report issues privately to the corresponding author at
<davide.marchini2@gmail.com>, including a minimal example, affected version,
and relevant build output.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

Issues are triaged against the latest `1.x` release.
